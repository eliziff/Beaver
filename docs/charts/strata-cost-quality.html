How to read the noise flags. Tax's two gen-7 points ({38, 48}) are the same treatment and the same route — the ~10-criteria spread is judge/replicate noise, so no single tax row is interpretable; only the strata mean (gen-7 ≈ 43) is. HSR/DPA/insurance sit inside their own ±2 noise band across generations, so gen-7 there is a cost lever, not a quality one. Employment's two 57s are both echo-v2 receipts (gen-7 and the 06-45-38 hybrid), which is the only place the honest-echo family clears the 53–54 band. Cost = uncached + 0.1·cached input tokens; a flash run's cached prefix re-reads dominate, so a lean route's value shows up as a lower cacheadj at equal score.
